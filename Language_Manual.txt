========================================================================
                      NOVALANG USER & SYNTAX MANUAL
========================================================================

1. COMPILATION AND SETUP
------------------------------------------------------------------------
To compile NovaLang from source:
  $ make

To clean temporary build files:
  $ make clean

To run a script:
  $ ./novalang <filename.nova>


2. SYNTAX SPECIFICATIONS
------------------------------------------------------------------------
* Variables & Assignment:
    let x = 10;
    let y = 20;

* Operations:
    let sum = x + y;
    let isGreater = x > y;

* Conditionals:
    if (x > 5) {
        print(x);
    } else {
        print(0);
    }

* Loops:
    while (x > 0) {
        print(x);
        x = x - 1;
    }

* Functions:
    fn add(a, b) {
        return a + b;
    }
    let res = add(5, 10);
    print(res);
