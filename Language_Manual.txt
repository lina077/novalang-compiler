                    NOVALANG USER & SYNTAX MANUAL

1. COMPILATION AND SETUP
------------------------------------------------------------------------
To compile NovaLang from source:
  $ make

To clean temporary build files:
  $ make clean

To run a single script:
  $ ./novalang <filename.nova>

To run all 15 test scripts at once:
  $ for f in variables.nova operators.nova conditionals.nova nested_conditionals.nova loops.nova functions.nova factorial.nova fibonacci.nova prime_checker.nova semantic_error.nova math_utils.nova average.nova sum_square_series.nova complex_logic.nova sum_series.nova; do echo "=== $f ==="; ./novalang "$f"; echo ""; done


2. SYNTAX SPECIFICATIONS
------------------------------------------------------------------------
* Variables & Assignment:
    var x = 10;
    var y = 20;

* Operations:
    var sum = x + y;
    var isGreater = x > y;

* Conditionals:
    if (x > 5) {
        print(x);
    } else {
        print(0);
    }

* Loops:
    while (x > 0) {
        print(x);
        x = x - 1;
    }

* Functions:
    fn add(a, b) {
        return a + b;
    }
    var res = add(5, 10);
    print(res);
